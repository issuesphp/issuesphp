## Introduction

The skeleton application for the IssuesPHP framework.

## Installation

- Composer

```bash
$ composer create-project issuesphp/issuesphp
```
-  Clone Project

```bash
$ git clone https://github.com/issuesphp/issuesphp.git
``` 

```bash
$ composer install
```

```bash
$ php issues.php
```

```bash
$ issuesphp:serve | Start a local server
```

```bash
$ issuesphp:make:migration | Creates a new migration
```

```bash
$ http://localhost:8080
```
